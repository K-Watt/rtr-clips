# Privacy policy: GTA Clipper

Last updated November 25, 2026.

GTA Clipper is a personal tool that only the owner of the YouTube channel rtr_clips uses. It is not offered to anyone else.

## What it accesses

With the owner's permission, granted through Google sign-in, GTA Clipper uses YouTube API Services to:

- upload Shorts to the rtr_clips channel and set whether they're public or private
- read the channel's own videos and their view counts
- read comments posted on the channel's own videos and post replies as the channel

## What it stores

The sign-in token stays only on the owner's own computer. View counts and comment text from the channel's own videos are kept there too, to decide what to post and how to reply. Nothing is sold or shared with anyone, and no data about anyone else's Google account is collected.

## Google and YouTube

GTA Clipper uses YouTube API Services. By using it you also agree to the [YouTube Terms of Service](https://www.youtube.com/t/terms), and Google's handling of data is covered by the [Google Privacy Policy](https://policies.google.com/privacy). Access can be removed at any time at https://myaccount.google.com/permissions.
